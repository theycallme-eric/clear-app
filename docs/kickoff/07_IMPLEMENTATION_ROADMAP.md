## Checkpoint Prompts

### Before Starting a Phase
1. Are dependencies complete?
2. Is the goal clear?
3. Are all tasks defined well enough to build?

### During Implementation
1. Is this task taking longer than expected? (Note it)
2. Did something unexpected come up? (Backlog it)
3. Is this creating technical debt? (Log it)

### After Completing a Phase
1. Did we achieve the goal?
2. What worked well?
3. What should we do differently?
4. What surfaced for the backlog?
