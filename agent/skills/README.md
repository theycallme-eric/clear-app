# Agent Skills Directory

This folder contains the Standard Operating Procedures (SOPs) for this project.
**Rule:** When a task matches a trigger below, READ and FOLLOW the corresponding skill file.

| Skill File | Trigger / Use Case |
| :--- | :--- |
| **`handoff.md`** | **START HERE.** Use when receiving a "Session Plan" from the planner. |
| **`component.md`** | Use when creating or refactoring UI components. Enforces Design System. |
| **`gallery_add.md`** | Use after creating a component to verify it visually. |
| **`debug.md`** | Use when a build fails or an error occurs. |
| **`admin_close_session.md`** | **END HERE.** Use to log work and update the backlog. |
| **`supabase_workflow.md`** | Use when touching Backend, Database, or Auth. |
