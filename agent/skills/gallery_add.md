# Skill: Add to Gallery
**Trigger:** After creating a new component.

1.  **Goal:** Create a visual test case.
2.  **Action:**
    * Open `src/pages/Gallery.tsx` (or create if missing).
    * Import the new component.
    * Append a new section showing the component in various states (Default, Loading, Error).
3.  **Verify:** Ask the user to visit `/gallery` to visually approve the design.
