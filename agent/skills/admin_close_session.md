# Skill: Admin & Close Session
**Trigger:** When all tasks in the session are complete.

1.  **Log Work:** Append a concise entry to `docs/SESSION_LOG.md`:
    * Date, Tasks Completed, Files Touched.
2.  **Update Backlog:** Mark items as `[x]` in `docs/BACKLOG.md`.
3.  **Architecture Check:** If you added a new "Page" or major "Service", update `docs/wireframes/PROJECT_MAP.md`.
4.  **Final Message:** Tell the user: "Session complete. Log and Backlog updated. Ready for next plan."
